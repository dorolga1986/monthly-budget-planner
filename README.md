# Тихий бюджет

Адаптивный одностраничный планировщик ежемесячного бюджета. Приложение работает без сборки и внешних зависимостей.

## Возможности

- Планирование доходов по нескольким источникам.
- Добавление, изменение и удаление категорий расходов.
- Ежемесячный взнос на цель накоплений.
- Автоматический расчёт расходов, накоплений и свободного остатка.
- Выбор месяца и валюты: тенге, рубли, доллары США или евро.
- Локальное сохранение плана в браузере.
- Адаптивный интерфейс для телефонов и компьютеров.

Смена валюты меняет только обозначение суммы; пересчёта по курсу нет. Данные бюджета остаются в браузере и не отправляются на сервер.

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются.

## Публикация

Сайт публикуется как статическая страница GitHub Pages из корня ветки `main`.
